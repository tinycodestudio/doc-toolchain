# Sample Project {#mainpage}

This is the **doc-toolchain** standalone example. It documents a one-header
library, [greet.h](@ref greet.h), to prove the toolchain works on any project —
not just the one it is vendored into.

Build these very docs with:

```sh
doc-toolchain/examples/run-example.sh
```

See the @ref greet_format function and the @ref greet_lang_t enum.
